# 安全策略

## 威胁模型

- 本库可能被嵌入到处理敏感数据的程序中。
- 主要风险包括：误用未经验证的密码实现、密钥或明文泄漏到日志、静态链接导致的内部状态副本不一致。

## 安全红线

- 禁止自创密码学。
- 密钥、明文、内部敏感状态不得写入日志或错误消息。
- 不得在失败路径上泄漏敏感信息。
- 新增密码实现必须使用经验证基元并附测试向量。

## 静态链接多副本风险

静态库被多个模块分别链接时会产生各自的内部状态副本。涉及密钥缓存或全局状态时必须明确语义，避免误以为全进程共享一份。
